Grundlagen

Was ist Vue?

Vue ist ein JavaScript-Framework für interaktive Benutzeroberflächen.

Bindung

verbindet Daten mit HTML

Reaktivität

aktualisiert die Oberfläche automatisch

Struktur

hilft beim Strukturieren grösserer Frontends

Grundlagen

Wann hilft ein Framework?

  • wenn viele UI-Zustände gleichzeitig gepflegt werden
  • wenn dieselben Daten an mehreren Stellen erscheinen
  • wenn Komponenten wiederverwendbar sein sollen
  • wenn die App mit der Zeit wächst
Praxis

Vue direkt im Browser laden


<div id="app"></div>

<script
    src="https://unpkg.com/vue@3/dist/vue.global.js">
</script>
<script src="./main.js"></script>

Für einen ersten Einstieg reicht die CDN-Version ohne Build-Tool.

Praxis

Die kleinste Vue-App


const { createApp } = Vue;

createApp({
    data() {
        return {
            title: "Hallo Vue"
        };
    }
}).mount("#app");

mount("#app") verbindet Vue mit einem HTML-Element.

Grundlagen

Reaktivität

Ändert sich ein Wert in data(), aktualisiert Vue die Oberfläche automatisch.


data() {
    return {
        count: 0
    };
},
methods: {
    increment() {
        this.count++;
    }
}
Grundlagen

Events mit v-on


<button v-on:click="increment">+1</button>
<button @click="increment">+1</button>

<p>Zähler: {{ count }}</p>

@click ist die Kurzschreibweise für v-on:click.

Quiz

Was steht nach 3 Klicks da?


<button @click="increment">+2</button>
<p>Zähler: {{ count }}</p>
                    

data() {
  return { count: 5 };
},
methods: {
  increment() {
    this.count += 2;
  }
}

Zähler: 11 - jeder Klick erhöht count um 2 (5 → 7 → 9 → 11), Vue aktualisiert den Text automatisch

Grundlagen

Eingaben mit v-model


<input v-model="name" placeholder="Dein Name" />
<p>Hallo {{ name }}</p>
                

data() {
    return {
        name: ""
    };
}

Vue hält Formularfeld und Daten automatisch synchron.

Grundlagen

Listen mit v-for


<li v-for="student in students" :key="student">
    {{ student }}
</li>
                

data() {
    return {
        students: ["Mia", "Noah", "Lea"]
    };
}
Grundlagen

Bedingungen mit v-if


<p v-if="notes.length === 0">
    Noch keine Notizen vorhanden
</p>
<ul v-else>
    <li v-for="note in notes" :key="note.id">
        {{ note.title }}
    </li>
</ul>

Statt viel DOM-Manipulation beschreibt man direkt den gewünschten Zustand.

Quiz

Was wird angezeigt?


<p v-if="notes.length === 0">
  Noch keine Notizen vorhanden
</p>
<ul v-else>
  <li v-for="note in notes"
    :key="note.id">
    {{ note.title }}
  </li>
</ul>
                    

data() {
  return {
    notes: [
      { id: 1, title: "Einkaufen" },
      { id: 2, title: "Lernen" }
    ]
  };
}

Eine Liste mit «Einkaufen» und «Lernen» - der <p> erscheint nicht, weil notes.length 2 ist (v-else greift)

Vergleich

Vue gegenüber Vanilla JS

Vanilla JS DOM oft direkt mit querySelector und innerHTML verändern
Vue UI aus Daten und Zustand beschreiben
Vorteil weniger manuelle Synchronisation
Praxis

Kleine Demo-Idee


<div id="app">
    <input v-model="newNote" placeholder="Neue Notiz" />

Was kommt in echten Vue-Projekten dazu?

  • computed für abgeleitete Werte
  • Lifecycle-Hooks für Laden und Initialisieren
  • Single File Components mit .vue-Dateien
