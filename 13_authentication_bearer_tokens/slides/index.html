Login

Login-Request


                        async function login(username, password) {
                            const response = await fetch(`${AUTH_URL}`, {
                                method: "POST",
                                headers: { "Content-Type": "application/json" },
                                body: JSON.stringify({ identity: username, password })
                            });

                            if (!response.ok) {
                                throw new Error(`Login fehlgeschlagen`);
                            }

                            return response.json();
                        }
Token

Token speichern


                        function saveToken(token) {
                            localStorage.setItem("authToken", token);
                        }

                        function getToken() {
                            return localStorage.getItem("authToken");
                        }

                        function clearToken() {
                            localStorage.removeItem("authToken");
                        }
Token

Authorization Header


                        const token = getToken();

                        const response = await fetch(`${BASE_URL}/notes`, {
                            headers: {
                                Authorization: `Bearer ${token}`
                            }
                        });
Jeder Request an einen geschützten Endpoint muss den Header Authorization: Bearer <Token> mitgeben – auch POST, PUT und DELETE.
Quiz

Was gibt dieser Code aus?


                        const token = "abc123";

                        const options = {
                            method: "POST",
                            headers: { "Content-Type": "application/json" },
                            headers: { Authorization: `Bearer ${token}` }
                        };

                        console.log(options.method, options.headers);

POST { Authorization: 'Bearer abc123' } – der zweite headers-Schlüssel überschreibt den ersten, Content-Type geht verloren. Alle Header gehören in dasselbe headers-Objekt.

Geschützte Daten laden


                        async function loadNotes() {
                            const response = await fetch(`${BASE_URL}/notes`, {
                                headers: { Authorization: `Bearer ${getToken()}` }
                            });
                            if (response.status === 401) {
                                clearToken();
                                showLogin();
                                throw new Error("Nicht autorisiert");
                            }
                            if (!response.ok) throw new Error(`HTTP ${response.status}`);
                            const notes = await response.json();
                            renderNotes(notes);
                        }
Quiz

Was passiert hier?

Der Server antwortet auf den Request mit Status 403. Was macht loadNotes()? Wird das Token gelöscht?


                        async function loadNotes() {
                            const response = await fetch(`${BASE_URL}/notes`, {
                                headers: { Authorization: `Bearer ${getToken()}` }
                            });
                            if (response.status === 401) {
                                clearToken();
                                showLogin();
                                throw new Error("Nicht autorisiert");
                            }
                            if (!response.ok) throw new Error(`HTTP ${response.status}`);
                            const notes = await response.json();
                            renderNotes(notes);
                        }

Es wird Error("HTTP 403") geworfen. Nur bei 401 werden clearToken() und showLogin() aufgerufen – das Token bleibt also gespeichert.

Login-Submit


                        loginForm.addEventListener("submit", async (event) => {
                            event.preventDefault();

                            const username = usernameInput.value.trim();
                            const password = passwordInput.value.trim();

                            const data = await login(username, password);

Sicherheit

Sicherheits-Hinweise (einfach)

  • Passwörter niemals im Frontend hardcoden
  • Token nicht in Logs ausgeben
  • In Produktion nur über HTTPS arbeiten
  • Token-Ablauf und Refresh kommen später
