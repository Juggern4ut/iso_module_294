Quiz

Was gibt dieser Code aus?


class Auto {
    constructor(marke, km) {
        this.marke = marke;
        this.km = km;
    }
    fahren(strecke) {
        this.km += strecke;
    }
}

const auto = new Auto("VW", 1000);
auto.fahren(250);
auto.fahren(50);
console.log(auto.marke + ": " + auto.km + " km");

VW: 1300 km - jeder Aufruf von fahren() verändert dasselbe Objekt

Themenblock 4: Async und Fetch


async function loadData() {
    const response = await fetch(API_URL);
    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    return response.json();
}

Wichtig:

Response prüfen
→
Fehler behandeln
→
Resultat weiterverarbeiten.
Quiz

In welcher Reihenfolge?


async function getPrice() {
    console.log("B");
    return 20;
}

async function main() {
    console.log("A");
    const price = await getPrice();
    console.log("C " + price);
}

main();
console.log("D");

A → B → D → C 20 - bei await pausiert nur main(), der restliche Code läuft weiter

Praxis

Mini-Wiederholung: DOM + Fetch


submitButton.addEventListener("click", async () => {
    const title = titleInput.value.trim();
    if (!title) return;

    await createNote({ title: title });
    await loadNotes();
});

Hier treffen Eventhandling, Validierung und asynchrones Arbeiten zusammen.

Fehlerquellen

Häufige Fehler

Selektoren stimmen nicht mit dem HTML überein

await fehlt bei asynchronen Aufrufen

Response wird nicht mit response.ok geprüft

Nach Änderungen wird die Ansicht nicht neu gerendert
