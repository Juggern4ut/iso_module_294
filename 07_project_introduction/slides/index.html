Praxis

Erstellen einer Codebase

  1. Erstellen Sie einen neuen Ordner notes-app
  2. Erstellen Sie darin die folgenden Dateien/Ordner
    • index.html
    • /css/styles.css
    • /js/main.js
  3. Erstellen Sie ein HTML5 Grundgerüst in der Datei index.html und binden Sie das CSS und JS ordnungsgemäss ein
Praxis

Git-Repository initialisieren

Navigieren Sie in ihrem Terminal in ihren Projektordner und führen Sie git init aus

Praxis

Github authentifizieren

  1. Neuen SSH-Key erstellen:
    ssh-keygen -t ed25519 -C "<mail>"
  2. Bestätigen aller Fragen mit Enter
  3. Inhalt der Datei
    C:/Users/<username>/.ssh/id_ed25519.pub kopieren
  4. In GitHub unter Profil → Settings → SSH and GPG keys → New SSH key einfügen
Praxis

Remote erstellen

1. Auf GitHub

Erstellen Sie in Ihrem GitHub-Account (oder ähnlich) ein neues Repository.

2. Lokal

Fügen Sie das Remote-Repository in ihrem lokalen Repository hinzu. 


                        git remote add origin git@github.com:<username>/<project-name>.git
Praxis

Ersten Commit erstellen

  1. Im Ordner der Codebase, alle Änderungen zum Repository hinzufügen: git add .
  2. Ersten lokalen Commit erstellen: git commit -m 'initial commit'
  3. Lokalen Commit auf die GitHub-Remote pushen: git push

Auf GitHub.com sollte der Code nun in Ihrem Repository vorhanden sein
